# Publishing dat.place

This repository owns only the personal homepage at https://dat.place/.

The Pages workflow publishes exactly index.html, style.css, script.js, 99lsxsry.png, CNAME and .nojekyll. It does not check out, build, copy or publish any other app. No cross-repository deploy keys are required.

Commits to main publish the homepage automatically. Keep CNAME set to dat.place. The homepage activity service remains at bio-backend.fly.dev in its own repository.
